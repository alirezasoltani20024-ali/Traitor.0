نسخه آماده Render - بازی خائن و خدمه

ساختار:
├── public/
│   ├── index.html
│   ├── game.js
│   └── style.css
├── server.js
├── package.json
└── README.txt

تنظیمات Render:
Build Command:
npm install

Start Command:
npm start

کنترل‌ها:
Z = انجام ماموریت
X = کشتن
C = جلسه / گزارش جسد

سرور از PORT متغیر محیطی Render استفاده می‌کند و index.html را از پوشه public سرو می‌کند.
