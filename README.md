# نفوذی — نسخه 2

ویژگی‌های این نسخه:
- فضای روشن و نقشه بزرگ بدون دایره دید
- نقشه کوچک در گوشه و نقشه بزرگ با دکمه ✕
- مأموریت‌های قرمز چشمک‌زن روی نقشه
- دکمه مأموریت کنار محل مأموریت
- شخصیت و سالن‌های نزدیک‌تر به سبک بازی‌های خدمه فضایی
- دکمه کشتن فقط برای خائن و فقط هنگام برخورد/نزدیکی خیلی زیاد
- گزارش جسد کنار جسد
- جلسه اضطراری فقط کنار میز
- ۳۰ ثانیه صحبت + ۱۰ ثانیه رأی‌گیری + نمایش نتیجه رأی‌ها و وضعیت اخراج
- ۲ خائن برای ۷ یا ۸ بازیکن
- نام یار خائن برای خائن‌ها قرمز نمایش داده می‌شود
- نقش بازیکن در شروع بازی فقط برای خودش و حدود ۲ ثانیه نمایش داده می‌شود
- خرابکاری برای خائن با زمان انتظار ۲ دقیقه
