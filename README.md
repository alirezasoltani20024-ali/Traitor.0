# نفوذی 1.2 FIXED
این نسخه مشکل دکمه‌های «ساخت اتاق» و «ورود» را برطرف می‌کند و ساختار سالن و راهروها را نگه می‌دارد.

نکته مهم: دکمه‌ها فقط وقتی کار می‌کنند که صفحه بتواند به سرور Socket.IO وصل شود. اگر روی Render هستید و دامنه Render برای شما باز نمی‌شود یا DNS آن به IP خصوصی 10.x.x.x resolve می‌شود، مشکل از اتصال به Render است نه دکمه‌ها.

Render:
Build Command: npm install
Start Command: npm start

### FIXED2 — محدوده دید واقعی
بازیکن‌های دیگر خارج از شعاع دید ۳۱۰ پیکسل اصلاً رسم نمی‌شوند و در صفحه دیده نمی‌شوند. محدوده دید برای هر بازیکن نسبت به موقعیت خودش محاسبه می‌شود.

### FIXED2 — محو شدن بازیکنان خارج از محدوده دید
بازیکن‌های دیگر وقتی بیش از ۳۱۰ پیکسل از بازیکن شما فاصله داشته باشند، اصلاً روی نقشه رسم نمی‌شوند؛ بنابراین بیرون از دایره دید کاملاً ناپدید هستند.
