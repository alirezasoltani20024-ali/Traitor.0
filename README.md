# Space Mystery Pro 2.0
نسخه آنلاین HTML/CSS/JavaScript + Node.js/Socket.IO.

## اجرا
Node.js نصب کنید، سپس:
npm install
npm start
سپس http://localhost:3000 را باز کنید.

برای لینک واقعی بین موبایل‌ها و کامپیوترها، این پروژه را روی یک هاست Node.js عمومی منتشر کنید و لینک همان سایت را ارسال کنید.

امکانات: ۳ تا ۸ نفر، اتاق و لینک دعوت، نقش خائن، دو خائن در اتاق‌های ۷-۸ نفره، حرکت، مأموریت، کشتن، جسد، گزارش، جلسه اضطراری، رأی‌گیری و شرایط برد.
