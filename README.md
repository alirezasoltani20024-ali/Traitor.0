# Space Mystery — FIXED5

نسخه جدید بازی چندنفره نفوذی.

تغییرات:
- بعد از رأی‌گیری و اخراج، اگر شرط برد برقرار شود، نتیجه برنده بلافاصله نمایش داده می‌شود.
- دیوارهای نقشه به صورت مشکی و ضخیم رسم شده‌اند و با برخوردهای سرور هماهنگ هستند تا دیوار نامرئی کمتر شود.
- مأموریت برق: ۵ سیم با رنگ‌های مختلف؛ باید هر سیم را به هم‌رنگ خودش بکشید.
- مأموریت اکسیژن: ۳ لوله و ۳ نشتی؛ با کلیک روی هر نشتی، همان نشتی بسته می‌شود.
- مأموریت حدس مین: ۱۰ دایره و دقیقاً ۲ مین؛ با انتخاب هر دو مین مأموریت کامل می‌شود و حدس اشتباه باعث شروع دوباره همان مرحله می‌شود.
- مأموریت دریافت فایل: کارت چهره بازیکن را به صورت رفت‌وبرگشتی بکشید؛ پس از شناسایی، دکمه دریافت فایل ظاهر می‌شود.
- نوار دریافت فایل دقیقاً ۵ ثانیه از ۰ تا ۱۰۰ پر می‌شود.
- در پایان دریافت فایل، تصویر ۱۰ دایره نمایش داده می‌شود که ۲ دایره قرمز محل همان دو مین مأموریت حدس مین را نشان می‌دهند.
- نمایش مأموریت‌ها بهینه‌تر شده تا ساخت و حذف مداوم دکمه‌ها در هر فریم باعث لگ نشود.

اجرا:
1. npm install
2. npm start
