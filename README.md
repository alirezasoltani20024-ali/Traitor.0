# نفوذی 1.1
نقشه جدید با ساختار شبیه Among Us: اتاق‌های بالا و پایین از طریق سالن مرکزی و راهروهای جانبی به هم متصل هستند.

ویژگی‌ها: ۳ تا ۸ بازیکن، خائن مخفی، دکمه‌های خائن فقط برای خائن، افشای نقش مقتول، نقشه بزرگ، دوربین، دید محدود، مأموریت، گزارش، جلسه، ادعای نقش بازیکن حذف‌شده، کنترل موبایل و WASD.

Render: Build Command = npm install / Start Command = npm start
